**Validación de entradas**



**Mayúsculas y minúsculas** 

EL juego no distinguirá entre mayúsculas y minúsculas 



Por ejemplo, si la palabra secreta contiene la letra A, 

el jugador podrá ingresar a o A, y ambas serán consideradas correcta



**Tildes**

El juego no toma en cuenta las tildes y omite las palabras con "ñ" 



**Mensaje**



El juego muestra mensajes claros ante cualquier situación 

que amenacé con romper su lógica. Por ejemplo:



* Si el jugador introduce un carácter que no corresponde a una letra válida, 

se mostrará un mensaje indicando que debe ingresar una letra.



* Si el jugador introduce una letra que ya había utilizado anteriormente,

&#x20;se mostrará un mensaje indicando que la letra ya fue utilizada.
